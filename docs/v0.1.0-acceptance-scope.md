## Requirements retained for v0.1.0

- Windows 10's outstanding OS-denied-network evidence, broader protocol/resource
  and Unicode relocation checks, clean-image/environment inventory, actual runtime
  version/native origins and target measurements remain required. The supplied
  smoke does not establish these claims. Use the existing
  [acceptance checklist](windows-acceptance.md); no new harness or VM setup is
  required by this documentation amendment.
- AGPL corresponding source/build/install material and notices, other bundled
  native/dependency redistribution obligations and final immutable source delivery
  remain required. The existing compliance blockers are unchanged.
- Exact worker/model identity, artifact integrity, reviewed final release
  materials, version-specific public metadata, consumer/support/trust docs and
  candidate-bound release review/rehearsal remain required.
- Final explicit approval of the exact verified release remains required.
  This decision neither approves publication nor marks any test passed.

Historical reports and the byte-pinned rc.1 manifest, compliance dossier and
embedded candidate instructions retain their original assembly-time scope.
Their two-OS wording is historical, not a continuing Windows 11 gate for v0.1.0.
Reconcile final public compatibility statements with this decision during release
preparation; preserve original hashes/evidence rather than editing existing
candidate artifacts in place. No implementation, dependency, package, build,
model asset or test result changes accompany this decision.
